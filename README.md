# web-blog`n`n前后端完全分离的中文博客仓库。`n`n- [frontend/](frontend/README.md)：Astro 静态站点，通过 HTTP API 获取内容。`n- [backend/](backend/README.md)：Django 内容服务，负责数据库、Admin、发布 API 和媒体。`n- [docs/](docs/)：架构、迁移和部署文档。`n`n## 本地联调`n`n先在 backend/ 启动 Django API，再在 frontend/ 配置 CONTENT_API_URL 和 CONTENT_MEDIA_ORIGIN 并运行 Astro。两个项目可以独立安装、测试和部署。`n`n详见 [前后端拆分方案](docs/designs/frontend-backend-separation.md)。
